# Selected game sound set

The user-selected batch 2, rendered in REAPER 7.73 at 48 kHz, stereo, 24-bit PCM. Four semitones down via coupled playback rate (0.793700526), 50 Hz high-pass, +2 dB low shelf at 350 Hz, -3.5 dB high shelf at 4.5 kHz. Transient Controller: attack +20%, sustain +8%, output -2.5 dB. Low-time take gain +2.5 dB.

Checkmate contains the complete edited check, a 60 ms pause, then the edited game-end cue. End also plays independently for resignation, timeout, and draw. Castle and premove are included for sound previews; those actions are not supported by the current rules/UI.

These are derivatives of the user-supplied Chess.com recordings at https://images.chesscomfiles.com/chess-themes/sounds/_MP3_/default/{name}.mp3. Source names: game-start, game-end, move-self, move-opponent, capture, castle, premove, move-check, promote, notify, illegal, tenseconds. Editing does not confer a new redistribution license.
